# Samith Edirisinghe — Portfolio

This repository contains my portfolio site. It covers my software engineering experience, education, and selected projects, including piano transcription research, Sinhala fake-news detection, and a Java racing system.

## View the site

Open `index.html` in a browser, or serve the repository with a local static file server. The site uses plain HTML, CSS, and JavaScript and does not need a build step.

## Update the content

- Edit `index.html` to change the profile, projects, experience, education, or contact details.
- Edit `assets/css/styles.css` for the page layout and styles.
- Edit `assets/css/theme-toggle.css` and `assets/js/theme-toggle.js` for the light and dark theme switch.
- Edit `assets/js/hero-intro.js` for the animated greeting.
